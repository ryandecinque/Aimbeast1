The plan

DayMain hourOptional, later
A daysRANK INT AZEUS BUILDER, then RANK INT A again
B daysRANK INT BRANK INT B again
  • RANK INT A: Smooth Thin Track V2, Air Track Smooth V3 150%, Air Control Sphere - S. 8 runs each, after a 2-run warm-up on the easier Air Control Sphere.
  • RANK INT B: Pasu Track Evo (RCT) - 0.85X, Pasu Track XYZ, Zeus Track Evo - Noblink. 8 runs each, after a 2-run warm-up on the slower Pasu Track Evo (RCT) - 0.6X.
  • ZEUS BUILDER: 7 drills, 2 runs each, that train the parts of Zeus Track: its fast direction changes and its sudden up/down jumps. It starts with a 2-run warm-up on the easier Zeus Track Evo - Noblink (EZ).
  • A 2–3 minute break away from the screen at every scenario switch.

Why this plan

  • Warm up first. In the practice log, the first run on each scenario scores about 3% below usual, and about 6% after a long break. Two easy runs at the start of each playlist take that cold-hands cost before the counted runs.
  • Spread out, not crammed. Each scenario gets 8 runs every other day, so there's a full day of rest between practising the same thing.
  • The slowest scenario decides the finish. All six need to reach Master 3, so extra time goes to the ones furthest away.
  • Zeus Track gets its own practice. It sat at the same weekly median for five weeks despite hundreds of runs, so its parts are trained separately. It's a trial: if Zeus hasn't moved by Oct 25, that time goes back to the Advanced playlist.
  • Intermediate only, for now. There's no evidence yet that Advanced practice speeds up Intermediate, so all extra time goes to the six target scenarios and Zeus Builder. Advanced comes back after the Oct 25 check-in if a scenario stalls, or once all six reach Master 3.
  • Ranked runs come first. Extra practice happens later in the day, so attempts at new ranks are always fresh.
  • Honest timeline. On current form every scenario is 5–7 ranks short of Master 3. That's months, not weeks, so progress is judged by the weekly trend.
